# 🌌 Todo Universe

A modern, responsive, and interactive to-do list web application built with **HTML, CSS, and JavaScript**. Todo Universe helps you organize daily tasks, habits, fitness goals, grocery lists, and weekly/monthly plans — all in one beautifully designed, space-themed interface.Smart unit suggestions, habit streak tracking, recurring tasks, and a responsive space-themed interface.

## ✨ Features

- 🔥 **Task Management** — organize tasks across daily, weekly, and monthly views
- 🌱 **Habit Tracker** — build habits with visual weekly streaks
- 🛒 **Grocery List Organizer** — keep shopping lists neat and structured
- 💪 **Fitness Goal Tracker** — log workouts and physical goals
- 🎯 **Smart Unit Suggestions** — auto-suggested units (kg, km, pages, glasses, etc.)
- 📅 **Due Dates & Times** — never miss a deadline
- 🔁 **Recurring Tasks** — automate repeating to-dos
- 📝 **Task Notes** — add context to any task
- 🚦 **Priority Levels** — High, Medium, Low
- 📊 **Live Progress Tracking** — visualize completion in real time
- ⭐ **Animated Space-Themed UI** — an immersive, polished interface
- 🎉 **Confetti Celebrations** — a fun animation when tasks are completed
- 📱 **Fully Responsive** — optimized for both desktop and mobile
